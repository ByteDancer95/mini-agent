# 周报模板（read_docs 工具的示例文档）

## 三段式结构

1. **本周进展**：写完成了什么，尽量带可核对的结果或数字，一句话一条。
2. **风险与阻塞**：写还没解决的问题、依赖的外部条件、需要谁协助。
3. **下周计划**：写下周要做的事，与待办清单保持一致。

## 写作约定

- 每条不超过两行，不写过程流水账。
- 结论前置，数据后置。
- 涉及外部事实（天气、资料、成本）时，先通过工具获取，不要凭记忆编造。

## 示例

> 本周进展：完成工具注册机制与 Schema 校验，覆盖 3 个必需工具。
> 风险与阻塞：真实 LLM 端点尚未配置，当前使用零密钥演示模式。
> 下周计划：补充多 session 隔离的回归测试并撰写 README。
